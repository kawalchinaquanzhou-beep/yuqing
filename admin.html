在这里增删改产品 → 点「保存并发布」→ 自动提交到 GitHub → Cloudflare 约 1 分钟后自动上线。全程不用碰代码。

① GitHub 连接（首次填写，自动记住）

Token 创建方法：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → 仓库选你的站点仓库 → Permissions 里 Contents 设为 Read and write → 生成后粘贴到这里。Token 只保存在你自己浏览器的本地存储里。
