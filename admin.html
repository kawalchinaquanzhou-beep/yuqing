YUQING 产品管理后台

在这里增删改产品 → 点「保存并发布」→ 自动提交到 GitHub → Cloudflare 约 1 分钟后自动上线。

① GitHub 连接（首次填写，自动记住）

② 当前产品列表

长按每行左侧的 手柄上下拖拽，即可调整产品在网站上的展示顺序。

图名称一级分类二级分类价格操作

③ 添加产品

④ 更新工厂宣传片

选择新宣传片，点「保存并发布」随产品一起上线。要求：MP4 且为 H.264 编码、24MB 以内。若视频是 H.265 编码或大于 24MB，页面会提示——那种情况把视频发给我处理（转码/外部托管）。

⑤ 发布上线

「保存并发布」会把修改后的产品数据（以及新上传的图片）一次性提交到 GitHub，Cloudflare Pages 检测到提交后约 1 分钟自动重新部署，你的域名随即更新。提交前可以随时在列表里继续编辑。
